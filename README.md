## About

Hi! I'm Jayant Kumar, an undergraduate cybersecurity researcher passionate about designing secure communication systems and advancing applied cryptography for the post-quantum era.

My research focuses on:

- Post-Quantum Cryptography (PQC)
- Quantum-Safe Communication Protocols
- TLS Security
- Internet Infrastructure Security
- Secure Distributed Systems
- Network Security

I independently conduct empirical cybersecurity research on cryptographic deployments across public internet infrastructure, including structured security assessments of enterprise-facing websites — analyzing TLS configurations, certificate chains, cipher suites, and cryptographic readiness for post-quantum migration.

I'm the developer of **AegisGuard**, an open-source platform for automated TLS analysis, Cryptographic Bill of Materials (CBOM) generation, and Post-Quantum Cryptography readiness assessment. The project was recognized as a **National Finalist in the Punjab National Bank Cyber Security Hackathon 2025–26**.

Beyond research, I build open-source cybersecurity tools, contribute to security automation, lead a CTF team, and explore secure systems engineering.
